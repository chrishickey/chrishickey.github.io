# chrishickey.github.io

Personal site for Chris Hickey. A single static page: `index.html` plus `css/style.css`.

- No build step. GitHub Pages serves the files as-is (`.nojekyll` disables Jekyll).
- `files/` holds the CV PDF, papers and transcripts.
- `images/` holds the profile photo and favicon.

To update the CV, rebuild it in the `cv-restyled` repo and copy `resume.pdf` to `files/ChrisCV.pdf`.
